## 🚀 3. Free Hosting On GitHub Pages (Step-by-Step)
To send this surprise website to Divya Priya:

1. Create a free account at [github.com](https://github.com) (if you haven't already).
2. Click **New Repository** (make it **Public**). Name it something like `divya-priya-surprise`.
3. Upload all files and folders:
   - `index.html`
   - `css/`
   - `js/`
   - `photos/`
4. Go to **Settings** > **Pages** inside your repository.
5. Under **Branch**, select `main` and `/ (root)` folder, then click **Save**.
6. Wait 1–2 minutes. GitHub will provide a live public HTTPS link (e.g. `https://<your-username>.github.io/divya-priya-surprise/`).
7. Test the link on your mobile phone, then share it with Divya Priya! ❤️
